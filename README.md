# 🤖 AI Agent Client

一个基于 **React Native + Expo** 构建的高性能、跨平台（iOS/Android/Web）多端智能体（AI Agent）客户端。界面采用极简的高级感暗黑/明亮双模设计，深度对标目前主流的消费级 AI 产品。

## ✨ 核心特性

- **跨平台架构**：基于 Expo Router 构建，完美适配移动端与桌面端。
- **大厂 UI/UX**：
  - 沉浸式双轨响应式布局（桌面端常驻侧边栏，移动端抽屉平滑滑入与蒙层过渡）。
  - 支持暗黑模式（Dark Mode）与明亮模式无缝切换。
  - 自适应多行输入框、精美 Markdown 气泡流与键盘平滑跟随。
- **原生级微交互**：
  - 完整的历史会话管理（新建对话、切换、状态保持与删除逻辑）。
  - 现代化、无侵入的自定义模态弹窗及动效。

## 🚀 快速上手

确保本地已安装 Node.js 与 Expo CLI。

```bash
# 1. 安装项目依赖
npm install

# 2. 启动开发服务器
npx expo start
